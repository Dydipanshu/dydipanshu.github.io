Payments Setup skill for Claude Code

The Payments Setup skill adds checkout, subscriptions and webhooks to your app with Stripe, Lemon Squeezy, Dodo Payments, Paddle or Polar. It verifies webhook signatures, makes event handling idempotent, grants access only after confirmed payment, and tests every billing event, including failed payments, cancellations and refunds.

Try it: "Add Lemon Squeezy subscriptions with a Pro plan to this app"

When should you use it?

  • Adding subscriptions or one-time payments
  • Putting features behind a paywall
  • Selling globally from India or other non-Stripe countries
  • Fixing unreliable webhook handling

What's inside the skill?

  1. Step 1: Choose the provider (if the user hasn't)
  2. Step 2: Model the products
  3. Step 3: Implement
  4. Step 4: Secrets and safety
  5. Step 5: Test

How do I get Payments Setup?

Payments Setup is included in Skillwright Pro and Founding Lifetime. After checkout you download the skill folder and copy it into ~/.claude/skills/.
