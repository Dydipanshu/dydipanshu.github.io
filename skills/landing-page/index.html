Landing Page skill for Claude Code

The Landing Page skill makes your AI agent position your product, write conversion copy section by section, and build a fast, accessible, SEO-ready landing page with pricing, FAQ and structured data. Try it: "Build a landing page for this product"

When should you use it?

  • Rewriting copy that isn't converting
  • Adding a pricing page and FAQ
  • Making a marketing site rank on Google

What's inside the skill?

  2. Step 2: Write the copy in this order
  3. Step 3: Build
  4. Step 4: Review before handing over
