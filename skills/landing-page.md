# Landing Page skill for Claude Code

The Landing Page skill makes your AI agent position your product, write conversion copy section by section, and build a fast, accessible, SEO-ready landing page with pricing, FAQ and structured data. It works in your existing stack or produces dependency-free HTML and CSS, and finishes with a conversion review.

Tier: premium

## When to use it

- Building a homepage or waitlist page
- Rewriting copy that isn't converting
- Adding a pricing page and FAQ
- Making a marketing site rank on Google

## What's inside

- Step 1: Positioning (do this before any code)
- Step 2: Write the copy in this order
- Step 3: Build
- Step 4: Review before handing over
