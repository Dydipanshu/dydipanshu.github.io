# Ship Check skill for Claude Code

The Ship Check skill runs a pre-launch production readiness review of your web app: leaked secrets, authorization holes, database security, error handling, monitoring, backups, performance and legal pages. It ranks findings as blockers, high or nice-to-have, fixes the blockers, and gives a clear ship or don't-ship verdict.

Tier: premium

## When to use it

- You're about to launch or deploy to production
- You built the app with AI and want a security review
- You're checking for leaked API keys
- You want a launch checklist done for you

## What's inside

- Step 1: Map the app
- Step 2: Review, in priority order
- Security
- Reliability
- Performance
- Business and legal basics
- Step 3: Report and fix
